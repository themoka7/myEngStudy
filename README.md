# 아빠 영어 — 뉴스·아티클 산출 훈련

회사에서 3분씩 틈틈이 돌리는 영어 훈련 웹앱. 설치·로그인 없이 URL만 열면 된다.

## 왜 이렇게 만들었나

영어를 배운 적은 있는데 오래 안 써서 감이 떨어진 상태에서 흔히 나타나는 세 증상은
사실 뿌리가 같다 — **덩어리(chunk) 단위로 저장이 안 되어 있는 것**.

| 증상 | 원인 | 이 앱의 처방 |
|---|---|---|
| 긴 문장이 안 만들어진다 | 단어 단위로 조립하려다 워킹메모리가 터진다 | **확장 드릴** — 짧은 뼈대에 수식어를 한 겹씩 |
| 과거분사가 헷갈린다 | 3단 변화표로 외워서 문장 안에서 안 나온다 | **분사 슬롯** — 수동·완료·수식 세 자리에 밀어 넣기 |
| 숙어를 쪼개서 해석한다 | 저장 단위가 너무 잘다 | **청크 카드** — 숙어를 문장째로 넣고 문장째로 꺼내기 |

모든 문항은 **한글을 보고 영어를 직접 쓰는** 방식이다. 읽어서 아는 것과 써낼 수 있는 것은 다르다.

## 카드 네 종류

- **청크** (40장) — `account for`, `in the wake of` 같은 뉴스 고빈도 숙어·연어를 문장 통째로
- **확장** (12세트 × 4단계) — `Revenue rose.` → `Driven by overseas demand, revenue rose 12 percent in the third quarter.`
- **분사** (15개 × 3슬롯) — 같은 동사를 수동태 / 현재완료 / 명사수식 세 자리에
- **청킹 리딩** (8개) — 긴 기사 문장을 의미 단위로, 되돌아가지 않고 한 방향으로

## 학습 설계

- **세션**: 3분(틈틈이) / 7분(커피 한 잔) / 15분(점심시간). 카드 종류별 부담을 계산해 시간에 맞춰 채운다.
- **간격 반복**: Leitner 5단계. 맞히면 1 → 2 → 4 → 8 → 16일 뒤로 밀리고, 틀리면 한 칸 내려온다.
- **즉시 재시도**: 틀린 카드는 같은 세션 끝에 한 번 더 나온다(점수에는 한 번만 반영).
- **채점**: 대소문자·구두점·하이픈 차이는 정답. 철자 오타는 정답 처리하되,
  `fell` → `fall` 같은 **같은 길이의 한 글자 치환은 시제 오류일 수 있으므로 봐주지 않는다.**
  틀린 단어는 정답 문장 위에 붉게 표시된다.

## 구조

```
index.html      화면
app.js          SRS 스케줄러 · 채점 · 카드 렌더링
style.css       라이트/다크 자동
data/chunks.js  청크 카드
data/expand.js  확장 드릴
data/pp.js      과거분사 슬롯
data/read.js    청킹 리딩
```

빌드 도구도 의존성도 없다. 데이터는 `window.DATA` 에 얹는 평범한 스크립트라
`file://` 로 열어도 돌아간다.

## 카드 추가하기

`data/` 안의 배열에 항목을 하나 더 넣으면 끝이다. id만 겹치지 않게 한다.

```js
{ id: "c041", chunk: "put off", gloss: "미루다",
  ko: "회의가 다음 주로 미뤄졌다.",
  en: "The meeting was put off until next week.",
  tip: "postpone 의 일상판. put 과 off 를 떼지 말 것." }
```

## 진도

진도는 브라우저 `localStorage` 에만 저장된다(서버 없음).
회사와 집에서 같이 쓰려면 홈 화면의 **내보내기 / 가져오기**로 JSON을 옮긴다.
